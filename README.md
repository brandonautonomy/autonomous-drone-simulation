# Autonomous Drone Simulation

An autonomous drone simulation project built using Python as part of my transition into Robotics and Artificial Intelligence.

## Objectives
- Learn drone flight dynamics
- Simulate autonomous movement
- Implement waypoint navigation
- Develop robotics and AI engineering skills

## Technologies
- Python
- Pygame
- NumPy
- ROS (future)

## Roadmap

### Phase 1
- Python fundamentals
- Basic 2D drone simulation
- Keyboard controls

### Phase 2
- Physics-based movement
- Hover stabilisation
- Waypoint navigation

### Phase 3
- Autonomous navigation
- ROS integration
- Obstacle avoidance
